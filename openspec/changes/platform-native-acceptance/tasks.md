# 任务清单：platform-native-acceptance

## 状态：IN_PROGRESS

## 执行约束
- 仅使用 proposal.md 和本文件追踪轻量 OpenSpec；进入实施后以本文件为准。
- 仓库缺少 openspec/config.yaml，按用户确认沿用现有项目约定继续。
- 每项任务独立验证后勾选，不以一次总体验收代替逐项证据。
- 缺少对应原生环境时保留待验收状态，不以 mock、VM 或交叉构建代替。
- 测试使用临时 home、独立 userData 和隔离注册表位置；禁止读写真实个人配置、用户环境或复用个人浏览器会话。
- 不自动提交、合并、推送或发布；每批应用代码修改前另行展示完整 diff 并确认。

## 任务
### Windows x64
- [ ] 1. 实现 Windows 注册表读取与快照：在隔离键验证七键、缺失值、值类型、Unicode 和权限错误，不读取真实用户环境。
- [ ] 2. 实现 Windows 七键提交：逐写入阶段注入失败，验证部分写入、回读失败、flush、通知失败及不自动回滚。
- [ ] 3. 实现 Windows 文件安全检查：真实 NTFS 测试 owner/DACL、reparse point、硬链接、数据流、特殊属性及文件占用。
- [ ] 4. 实现 Windows 安全文件替换：验证临时文件访问权限、替换前冲突、元数据保持、失败后状态与清理，不承诺 POSIX 目录同步语义。
- [ ] 5. 集成 Windows 存储：临时配置与隔离注册表联合验证 CRUD、切换、settings 遮蔽及部分写入结果。
- [ ] 6. 执行 Windows 原生验收：非管理员隔离账户验证安装包、真实文件权限、用户环境持久化、部分失败和应用重启。

### Linux（Ubuntu 22.04/24.04 x64）
- [ ] 7. 实现 Linux 元数据检测：用真实临时文件覆盖普通属性、xattr、ACL、flags、检测失败及不支持文件系统。
- [ ] 8. 集成 Linux 激活目标：验证账户登录 shell 到 bash/zsh 文件映射、其他 shell 拒绝、缺文件反馈与七键转义。
- [ ] 9. 执行 Ubuntu 原生验收：22.04/24.04 x64 验证安装包、bash/zsh 与元数据拒写；不预装额外检测工具。

### macOS x64 与安装包
- [ ] 10. 执行 macOS x64 原生验收：目录包、CRUD、切换、错误恢复与 settings 不变证据。
- [ ] 11. 配置并验证三平台安装包：DMG、NSIS、AppImage；检查产物白名单、原生模块加载、非仓库工作目录启动，排除测试数据、配置密钥和日志。

### 迁移遗留验收
- [ ] 12. 验收单实例锁与 activate 重激活：需复用同一 userData 的真实场景。
- [ ] 13. 验收原生剪贴板写入：使用另行授权的隔离账户/会话或虚拟机及合成文本，不读取个人剪贴板。
- [ ] 14. 完成迁移全量 diff 的独立审查：覆盖 Electron 主进程、preload、IPC、文件层与页面客户端。

## 验收标准
- [ ] macOS、Linux、Windows 分别写入已确认目标，不执行配置、不修改其他 shell profile。
- [ ] Linux 元数据检测无需用户另装工具；不支持情况安全拒写，Windows 文件权限及安全属性不被静默丢失。
- [ ] Windows 七键非原子写入的部分失败与通知失败被准确表达，不自动重放或盲目回滚。
- [ ] 支持矩阵中的各平台及架构均有对应原生验收证据；缺少环境的项目保持未完成，不以 mock 代替。
- [ ] 安装包可在对应系统启动，未签名限制已说明，不携带个人配置或测试秘密。
