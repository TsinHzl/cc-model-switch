## Purpose

在桌面应用中提供基于本机已配置模型与网关的在线对话能力，包含会话历史、流式回复、思考过程、附件与联网搜索，且不修改任何本机配置文件。renderer 仅提交 model + base_url 与消息体，主进程按配置条目解析密钥并受限转发，密钥与目标 URL 永不进入 renderer。

## Requirements

### Requirement: 页面切换与配置页隔离

系统 SHALL 在桌面应用内提供「模型切换」与「对话」两个页面入口；切换页面不得改变配置页既有行为，也不得在进入对话页时发起配置写入。

#### Scenario: 切换到对话页
- **WHEN** 用户点击「对话」入口
- **THEN** 显示对话页，配置页的列表、搜索、增删改状态不被修改

#### Scenario: 切回配置页
- **WHEN** 用户在对话页生成进行中切回配置页
- **THEN** 配置页正常展示；对话生成可继续或在返回时展示已完成内容，配置数据不被改动

### Requirement: 对话请求由主进程受限转发

系统 SHALL 仅通过固定 IPC 发起对话请求：renderer 只提交模型与网关标识（model + base_url）及对话参数，主进程重新读取最新 config 按 model + base_url 定位条目，自行解析密钥并决定请求头。renderer MUST NOT 提交密钥、任意 URL、文件路径、命令或自定义请求头；密钥 MUST NOT 出现在任何 IPC 请求、响应或事件中。

#### Scenario: 合法请求
- **GIVEN** 配置列表中存在该 model + base_url，且 base_url 为 http(s)
- **WHEN** renderer 提交对话请求
- **THEN** 主进程向该条目的 base_url 发起请求，密钥只用于请求头，不返回给 renderer

#### Scenario: 请求携带密钥字段
- **WHEN** 请求中包含 key 或其他额外字段
- **THEN** 按严格结构校验拒绝，不发起任何网络请求

#### Scenario: 目标不在配置中
- **WHEN** 提交的 model + base_url 在最新配置中找不到，或 base_url 不是 http(s)
- **THEN** 拒绝请求并返回有限错误码，不发起任何网络请求

#### Scenario: 非可信来源
- **WHEN** 请求不来自当前可信窗口的存活主 frame
- **THEN** 拒绝请求，不发起网络请求

#### Scenario: 重定向或证书异常
- **WHEN** 上游返回任何 3xx 响应，或 TLS 握手/证书校验失败
- **THEN** 终止该次请求并作为错误上报，不跟随重定向、不转发密钥、不关闭证书校验

### Requirement: 流式回复与取消

系统 SHALL 以流式方式把上游增量回传 renderer，并在用户停止或窗口关闭时中止该次请求。

#### Scenario: 流式增量
- **WHEN** 主进程收到上游文本或思考增量
- **THEN** 按请求 id 通过只读事件通道推送，renderer 逐字展示，不阻塞输入

#### Scenario: 用户停止生成
- **WHEN** 用户在生成中点击停止
- **THEN** 中止上游连接，已收到的内容保留并标记为已中断，不自动重试

#### Scenario: 上游未正常结束
- **WHEN** 连接结束但未收到结束事件
- **THEN** 该条回复标记为错误并提示可能不完整，不自动重放请求

#### Scenario: 并发请求
- **WHEN** 已有对话请求在途时再次提交
- **THEN** 拒绝新请求并提示稍后重试，不排队

### Requirement: 对话页模型与参数选择

系统 SHALL 从当前配置列表派生可选模型，模型与网关成对选择；思考力度按模型能力收敛，联网搜索为显式开关。

#### Scenario: 选择模型
- **WHEN** 用户选择某个配置条目
- **THEN** 后续请求使用该条目的 model 与 base_url

#### Scenario: 配置为空
- **WHEN** 配置列表为空或不可读
- **THEN** 对话页提示无可用模型，禁用发送，不自动创建配置

#### Scenario: 思考力度不适用
- **WHEN** 已保存的档位不被当前模型支持
- **THEN** 收敛为受支持的档位，不发出不受支持的电平字段

### Requirement: 会话历史本地保存

系统 SHALL 将会话保存在 renderer 本地存储，提供新建、选择、删除、清空；不写入任何配置文件，不上传服务端。

#### Scenario: 首条消息后保存
- **WHEN** 用户发出第一条消息
- **THEN** 创建会话并以首条消息开头生成标题，刷新应用后可恢复

#### Scenario: 本地存储不可用或超限
- **WHEN** 写入本地存储失败
- **THEN** 当前会话仍可在内存中使用，并提示历史可能不会保留，不中断对话

#### Scenario: 清空历史
- **WHEN** 用户确认清空全部历史
- **THEN** 删除本地会话记录并回到新对话，不触碰配置文件

### Requirement: 附件与不可信内容处理

系统 SHALL 支持图片（png/jpeg/gif/webp）与 UTF-8 文本文件作为附件随消息发送，并限制单条消息附件数量与文本体积。

#### Scenario: 不支持的附件
- **WHEN** 用户选择非上述图片格式、PDF、二进制或非 UTF-8 文件
- **THEN** 拒绝该文件并提示原因，不发送

#### Scenario: 模型回复渲染
- **WHEN** 回复包含 Markdown、原始 HTML 或图片语法
- **THEN** 按受限 Markdown 渲染：原始 HTML 转义为纯文本、链接仅放行 http(s)、图片语法不发起远端请求

#### Scenario: 请求体超限
- **WHEN** 单次对话请求的紧凑 JSON 等价字节数超过 8 MiB
- **THEN** 拒绝请求并提示，不静默截断历史消息

#### Scenario: 复制回复
- **WHEN** 用户复制回复内容
- **THEN** 经既有只写剪贴板通道写入，失败时提示，不自动重试
